# Kitchen Equipment Sales Performance Analysis

## 📌 Project Overview

This project is an end-to-end data analytics project developed during the **KarirNex Data Analyst Bootcamp Batch 6**.

The project focuses on analyzing kitchen equipment sales transactions to identify sales performance trends, product contribution, customer behavior, and business opportunities through data-driven insights.

The analysis workflow covers data preparation, SQL analysis, exploratory data analysis, and interactive dashboard development.

---

## 🎯 Objectives

The objectives of this project are:

- Analyze overall sales performance
- Identify top-performing products and categories
- Understand sales trends over time
- Evaluate customer purchasing patterns
- Provide business recommendations based on data insights

## 🔄 Project Workflow

### 1. Data Preparation

Performed initial data preparation using Microsoft Excel, including:

- Data cleaning
- Data validation
- Data formatting
- Dataset preparation for analysis


### 2. SQL Analysis

Used Google BigQuery to perform analytical queries, including:

- Sales performance analysis
- Product analysis
- Category contribution analysis
- Customer purchasing analysis


### 3. Exploratory Data Analysis (EDA)

Conducted data exploration using Python to:

- Understand dataset characteristics
- Perform data aggregation
- Generate analytical visualizations


### 4. Dashboard Development

Built an interactive dashboard using Looker Studio to visualize:

- Sales performance
- Monthly trends
- Category performance
- Product contribution
